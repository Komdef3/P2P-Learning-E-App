# P2P-Learning-E-App
Peer-to-Peer E-Learning App
Summary:
Many e-learning platforms focus on instructor-to-student communication and provide limited opportunities for peer collaboration. Students often need a platform that supports group learning, resource sharing, and real-time interaction. Traditional learning management systems operate on a top-down content delivery model where instructors create content, and students consume it passively, failing to leverage the most valuable educational resource: peer knowledge.

Objective:
To develop a Peer-to-Peer e-Learning Platform (StudyHub) that enables collaborative learning through messaging, learning groups, and content sharing while maintaining a scalable and maintainable architecture using modern software construction principles and DevOps practices.

Methods:
The system was designed using software engineering principles such as modularity, abstraction, encapsulation, and separation of concerns. Flutter was used for the frontend, Firebase for backend services, Docker for containerization, and Jenkins for CI/CD automation. The development followed an incremental methodology with continuous integration and testing.

Key Results
The platform successfully integrates:
•	User Authentication
•	Profile Management
•	Learning Groups
•	Real-Time Messaging
•	Content Sharing
•	Docker Deployment
•	Jenkins CI/CD Pipeline
